# 💼 Calculadora de Comissão em Java

Projeto desenvolvido para fins de estudo acadêmico, com o objetivo de praticar lógica de programação, manipulação de variáveis do tipo decimal (double) e entrada/saída de dados utilizando a linguagem *Java*.

---

## 🚀 Sobre o Projeto
O programa simula um sistema de folha de pagamento para vendedores. Ele realiza a leitura dos dados do funcionário, calcula a comissão baseada no total de vendas mensais e exibe o resumo financeiro final.

### 📋 Regras de Negócio:
1. *Entrada de dados:* O usuário informa o nome do funcionário, o salário fixo e o valor total de vendas realizadas no mês.
2. *Cálculo da Comissão:* O sistema aplica automaticamente *15%* de comissão sobre o total de vendas (Total de Vendas * 0.15).
3. *Salário Total:* Soma o salário fixo com o valor da comissão calculada.
4. *Saída formatada:* Exibe na tela o nome do funcionário, o salário fixo e o salário final consolidado.

---

## 🛠️ Tecnologias Utilizadas
* *Java* (JDK 17+)
* *IntelliJ IDEA* (Ambiente de Desenvolvimento)
* java.util.Scanner (Para leitura de dados via console)

---

## ⚙️ Como Executar o Projeto

1. Certifique-se de ter o *Java JDK* instalado na sua máquina.
2. Clone este repositório ou baixe os arquivos fonte (.java).
3. Abra o arquivo Comissao.java na sua IDE de preferência (como IntelliJ IDEA, Eclipse ou VS Code).
4. Compile e execute a classe principal Comissao.
5. Insira os dados solicitados no terminal (Nome, Salário Fixo e Total de Vendas).
